# 双串口整片 EEPROM 清零指令

适用固件：`Output/BPCOME-3502-260929-V2.hex`。调试报文版本为 `260929-V2`。

## 使用

两个端口均为 **115200，8数据位，无校验，1停止位，无流控**。

| 端口 | 单片机 TX | 单片机 RX | 支持指令 |
|---|---|---|---|
| DEBUG / UART4 | PC10 | PC11 | `ClearRuntime`、原有 `Reset` |
| CPU / UART5 | PC12 | PD2 | `ClearRuntime` |

发送ASCII文本 `ClearRuntime`，追加回车、换行或CRLF，区分大小写，无空格和参数。完整字节：

```text
43 6C 65 61 72 52 75 6E 74 69 6D 65 0D 0A
```

串口助手选择文本发送并勾选追加CRLF即可；不要发送字面量反斜杠字符 `\r\n`。

操作成功后，**来源串口**返回一行：

```text
ClearRuntime:OK
```

失败返回：

```text
ClearRuntime:ERROR EEPROM
```

擦除及回执由任务执行，收到指令后需要等待任务轮询、512页擦写及回读，不能按立即回复处理。CPU回执在健康报文之间发送，不插入报文中间；与正常上报共用串口，接收端按行识别回执。成功后可观察 `RUNTIME:0h0m NEXT_SAVE_IN:30`，此后继续累计，约一分钟显示1分钟。

## 清除范围和执行步骤

1. UART4/UART5各自按行接收，中断只登记请求；超长、含NUL或带接收错误的行整行丢弃，CRLF不会触发两次。
2. Sensor_Task在采集前执行清除，和温度采集、自动保存共用模拟I2C的访问保持串行。全过程不关闭中断；GPIO任务、风扇边沿转发及CPU串口任务仍可运行。擦除期间传感器采集暂缓，CPU上报可能沿用上次采样值。
3. 从地址0到65535逐页写入 `0xFF`，每页128字节、共512页；每页均等待EEPROM内部写周期结束并逐字节回读确认。包含旧计时地址128、自检页及其他全部数据。
4. 全片擦除成功后，在256和384重建累计时长为零的CRC双备份，并回读验证；其他地址仍为 `0xFF`。因此完成后并非所有字节都保持 `0xFF`，两份记录用于确保重启从零历史开始。
5. 清零RAM历史、当前开机秒数、tick余数及保存进度，以操作完成时刻作为新计时起点。之后按原策略累计并在30分钟边界保存。

擦除过程中对外累计时间显示未知（`RUNTIME:N/A`），确认完成后才发布有效的零值。命令不会复位CPU，也不会执行PA0的Reset脉冲。

同一端口保持忙状态，直到回执最后一个停止位发送完成。此期间的重复ClearRuntime合并；忙状态期间开始接收、回执结束后才收全的分段重发也不会再次擦除。两端口在执行开始前或执行期间请求会共用本次擦除，并分别返回结果。回执完整发送后开始接收的新指令是一次新的完整擦除；本协议无请求编号，无法区分回执结束后的重试与新指令。

DEBUG回执整串持有支持优先级继承的发送互斥量，GPIO的printf及其他DEBUG发送入口共用此锁，因此不会插入回执内部。正常115200-8N1下，OK回执在线发送约1.7ms，ERROR回执约2.5ms；GPIO任务碰到正在发送的回执时需等待其结束，实际等待还受调度影响。发送等待不关闭中断，风扇边沿中断及SysTick仍可抢占；普通日志行之间不保证整行互斥。

TXE/TC改为有限次数轮询；外设不响应时释放发送锁，保留命令结果，下一次任务轮询仅重发回执，不重新擦除EEPROM。轮询次数不是精确的毫秒超时。ISR/异常上下文跳过串口发送，避免高优先级中断中的打印阻塞tick；该路径的诊断信息需通过调试器检查。启动前日志正常发送；临界区/暂停调度中的发送只尝试立即取得锁，不阻塞等待其他任务。

## 失败与断电

任何一页写入、就绪等待、回读或零备份建立失败，都返回ERROR；EEPROM此时可能只被部分擦除。当前开机期间保持 `RUNTIME:N/A` 并暂停自动保存，避免旧RAM累计值重新写回；排除通信/写保护/供电问题后重新发送ClearRuntime，直到收到OK。

全片擦除不是断电原子操作；中途断电可能留下旧记录、空白或部分写入记录，下次开机的恢复结果取决于中断位置。若未收到OK，不应认定清除成功，重启后应重新发送并等待成功。成功后复位不会恢复旧时长，但正常运行的新时间仍遵循每30分钟保存的策略。

原有上电 `eeprom_test()` 会重写0–127的自检页；这是开机自检行为，不代表旧累计时间恢复。

主机运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Tests\run_runtime_tests.ps1
```

已通过：14组计时/保存测试（包括512页全擦除、全地址验证、重启零历史、任意选定页及两份零备份写入失败、回读失败、失败后禁止自动回写及重新清除）；风扇边沿回归；双串口组行、CR/LF、同时请求、执行中加入请求、结果返回、发送中重复合并、跨回执边界的分段重发、发送失败仅重发结果、错误输入、Reset兼容性测试；真实双线程竞争测试覆盖printf字符/单字节/半字/数组/字符串五类DEBUG发送入口，以及CPU独立发送、TXE/TC超时后释放锁、ISR/临界区保护、超过255字节数组。Keil ARMCC5编译链接0错误0警告。测试未连接实板。

上板分别从两个串口发送命令，确认来源口返回OK、两口显示归零、运行一分钟后继续增加、复位后旧累计值不再出现；同时观察风扇及GPIO工作。断开EEPROM或使能写保护时应返回ERROR而非OK，恢复后重发应成功。
